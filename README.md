# Радиальная фильтрация к скважине с послепритоком

Курсовая по матфизике в нефтегазе. Нестационарный приток к скважине конечного радиуса. Решение реализовано двумя способами — аналитически (через преобразование Лапласа) и численно (конечные разности) — с взаимной проверкой.

## Постановка задачи

Уравнение пьезопроводности в осесимметричной постановке:

```text
∂Δp/∂t = κ · (1/r) · ∂/∂r ( r · ∂Δp/∂r ),   r_w < r < r_e
```

где `Δp = p_i − p`, `κ = k / (φ·μ·c_t·B)`.

Граничные условия:
- `r = r_e`: `∂Δp/∂r = 0` (непроницаемая граница);
- `r = r_w`: `q = (p_w − b) / a`, `q_s = q + C_s · dp_w/dt` (учёт послепритока).

Начальное условие: `p(r,0) = p_i`.

## Параметры (по умолчанию)

- `k = 50e-15 м²`
- `φ = 0.2`
- `μ = 10e-3 Па·с`
- `c_t = 5e-10 1/Па`
- `h = 10 м`
- `r_w = 0.1 м`
- `r_e = 300 м`
- `p_i = 250 бар`
- `b = 150 бар`
- `a = 2e10 Па/(м³/с)`
- `C_s = 0; 1e-6; 5e-6; 2e-5 м³/Па`

Все параметры вынесены в начало скриптов для удобства изменения.

## Методы решения

**Аналитический:** Переход к изображениям по Лапласу. Комбинация `Φ(r) = I₀(λr)·K₁(λr_e) + K₀(λr)·I₁(λr_e)`, где `λ = √(s/κ)`, автоматически удовлетворяет условию `∂Φ/∂r|_{r_e}=0`. Из граничного условия на скважине находятся `\bar{Δp}_w(s)`, `\bar q(s)` и `\bar q_s(s)`.

**Численный:** Замена `z = ln(r/r_w)` для сгущения сетки у скважины. Неявная схема по времени, центральные разности по пространству. Система решается методом прогонки. Внутреннее граничное условие учитывает `C_s`.

## Строящиеся графики

- `Δp_w(t)` для разных `C_s` (совмещение аналитики и ЧД);
- профили `Δp(r,t)` и `p(r,t)`;
- `q(t)`, `q_s(t)`, `q_s(p_w)`;
- индикаторная зависимость `q(Δp_w)`;
- проверка баланса `(q_s − q) + C_s·dΔp_w/dt ≈ 0`;
- вывод погрешности численного решения относительно аналитики.

## Ожидаемый результат

При `C_s = 0` конечно-разностное и аналитическое решения совпадают с погрешностью в единицы процентов. При `C_s > 0` на ранних временах наблюдается плато на `p_w(t)`: ствол скважины работает как буфер, `q_s` поддерживается за счёт упругости, а `q` нарастает постепенно. С ростом `C_s` переходный режим удлиняется.
