# Радиальная фильтрация к скважине с послепритоком

Курсовая по матфизике в нефтегазе. Нестационарный приток к скважине конечного радиуса, решение двумя способами — аналитически (Лаплас) и численно (конечные разности) — с взаимной проверкой.

## Постановка

Уравнение пьезопроводности в осесимметричной постановке:

```
∂Δp/∂t = κ · (1/r) · ∂/∂r ( r · ∂Δp/∂r ),   r_w < r < r_e
```

где `Δp = p_i − p`, `κ = k/(φ·μ·c_t·B)`.

Граничные условия:
- `r = r_e`: `∂Δp/∂r = 0` (непроницаемая граница);
- `r = r_w`: `q = (p_w − b)/a`, `q_s = q + C_s·dp_w/dt` (послеприток).

Начальное условие: `p(r,0) = p_i`.

## Файлы

| Файл | Что делает |
|------|-----------|
| `Аналитическое решение.py` | Решение в Лапласе через функции Бесселя, обратный переход `anaflow.get_lap_inv` (Stehfest) |
| `Численное решение.py` | Неявная схема + прогонка (TDMA), сравнение с аналитикой при `C_s = 0` |
| `Pieso_eq_unsteady_state.py` | Вспомогательный/отладочный |
| `Курсач_Юдин_2_сем.pdf` | Пояснительная записка |

## Параметры (по умолчанию)

`k=50e-15 м²`, `φ=0.2`, `μ=10e-3 Па·с`, `c_t=5e-10 1/Па`, `h=10 м`,
`r_w=0.1 м`, `r_e=300 м`, `p_i=250 бар`, `b=150 бар`, `a=2e10 Па/(м³/с)`,
`C_s = 0; 1e-6; 5e-6; 2e-5 м³/Па`.

Все параметры вынесены в начало скриптов.

## Методы

**Аналитический.** Переход к изображениям по Лапласу. Комбинация
`Φ(r) = I₀(λr)·K₁(λr_e) + K₀(λr)·I₁(λr_e)`, `λ = √(s/κ)`, автоматически даёт `∂Φ/∂r|_{r_e}=0`. Из граничного условия на скважине находятся `\bar{Δp}_w(s)`, `\bar q(s)`, `\bar q_s(s)`; обратное преобразование — `anaflow.get_lap_inv`.

**Численный.** Замена `z = ln(r/r_w)`, неявная схема по времени, центральные разности по пространству, решение трёхдиагональной системы методом прогонки. Внутреннее ГУ — с учётом `C_s`.

## Графики

- `Δp_w(t)` для разных `C_s` (аналитика и FD на одном графике);
- профили `Δp(r,t)` и `p(r,t) = p_i − Δp`;
- `q(t)`, `q_s(t)`, `q_s(p_w)`;
- `q(Δp_w)` — индикаторная зависимость;
- проверка баланса `(q_s − q) + C_s·dΔp_w/dt ≈ 0`;
- отчёт о погрешности FD относительно аналитики.

## Ожидаемый результат

При `C_s = 0` FD и Лаплас совпадают с погрешностью в единицы процентов (точное значение выводится в консоль). При `C_s > 0` на ранних временах — плато на `p_w(t)`: ствол работает как буфер, `q_s` держится за счёт упругости, а `q` нарастает постепенно. С ростом `C_s` переходный режим удлиняется.
